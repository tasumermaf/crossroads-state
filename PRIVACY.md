# Public-data boundary

This package contains a general finite-state implementation and newly generated
synthetic fixtures. It is deliberately separate from the private source study
that motivated the prototype.

## Included

- Mathematical definitions of additive changes, reader permutations, passive
  coordinate changes, exact checkpointing and journal replay.
- Public synthetic rational fields generated by the formulas in
  `src/crossroads_state/synthetic.py`.
- Synthetic reading windows, reference addresses, instructions and test results.
- A methods paper with bibliographic references to publicly accessible sources.

## Excluded

- Original private numerical arrays and their source reading windows.
- Reserved observed grids and data that reproduce those grids as the source
  system's selected readings.
- Historical source quotations, photographs, manuscripts, dictionaries,
  inscription names, associated private values, personal information and
  credentials.
- Private filesystem paths, internal infrastructure addresses and source URLs
  requiring access to the originating archive.

The letters A and B name **public synthetic operations**. They are not a release
of the similarly named private numerical fields. The use of 81 addresses and
six instruction names preserves a useful test architecture without importing
the private source dataset.

The public results are a new 512-trace study. They do not silently substitute
for, aggregate with, or re-label the earlier private validation. The latter is
not needed to reproduce any result in this package.

No privacy assurance can cover arbitrary files a future contributor adds.
Review new fixtures, images, examples and logs before publishing them. Do not
copy a protected reading window alongside an array from which it reads reserved
content. The package itself contains no external-service upload function.
